# けんびきょうラボ

顕微鏡の使い方を確認・練習する、小学生向けの学習サイトです。

## できること

- **ぶいんを しろう**：three.js の3D顕微鏡をドラッグで回しながら、部位のボタンを押すとその場所が光り、名前とはたらきを学べます（12部位）。ナビキャラが部品の見方を案内します。
- **てじゅん チャレンジ**：顕微鏡を使う手順を10ステップで体験します。各場面に合ったナビキャラのヒントを表示し、レンズをぶつけそうな操作では注意を促します。
  1. 反射鏡で視野を明るくする
  2. プレパラートをステージにのせる
  3. 見たいものを真ん中へ動かす（像は上下左右が逆に見えることも体験）
  4. 横から見ながら対物レンズを近づける（ぶつかると注意される）
  5. のぞきながら粗動ねじでピントを合わせる
  6. 微動ねじで仕上げる
  7. レボルバーを回して100倍＋ピント合わせ直し
  8. 400倍にチャレンジ
  9. しぼりで明るさを調節する（高倍率では暗くなる）
  10. かたづけ（低倍率に戻す→プレパラートを外す）

部位名と手順は、理科教育サイト（さわにい「中学理科・顕微鏡の使い方」、lylle「実験と観察・顕微鏡の使い方」）で最終確認しました。

接眼レンズから見える景色（池の水の微生物）は、明るさ・ぼやけ・倍率・位置が操作に連動します。

## 技術

- three.js（`vendor/three.min.js`、TT-sensei/3dtest と同じもの）で顕微鏡をモデリング
- ナビキャラは `TT-sensei/navi-character-` の公開済みWebPを参照し、教材リポジトリへ複製しません。
- 画像が読み込めない場合も、操作と学習は続けられます。
- 外部API・DBなし。単一ページ（index.html + app.js）
