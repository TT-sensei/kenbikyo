# けんびきょうラボ

小学生が、顕微鏡のパーツの名前とはたらき、観察の基本的な手順を体験しながら学べる教材です。

## できること

- **パーツを しろう**：3D顕微鏡をドラッグで回し、パーツのボタンを押すと該当部分が光ります。名前とはたらきを確認できます（12パーツ）。ナビキャラが見方のヒントを伝えます。
- **てじゅん チャレンジ**：顕微鏡を使う手順を10ステップで練習します。ナビキャラが場面に応じたヒントを出し、対物レンズをプレパラートにぶつけないための注意も学べます。
  1. 反射鏡で視野を明るくする
  2. プレパラートをステージにのせる
  3. 見たいものを視野の中央に移す（像が上下左右逆に見えることを体験）
  4. 横から見ながら対物レンズをプレパラートに近づける
  5. のぞきながら、大きい調節ネジでピントを合わせる
  6. 小さい調節ネジでピントを仕上げる
  7. レボルバーを回して倍率を上げ、ピントを合わせ直す
  8. さらに高い倍率で観察する
  9. しぼりで明るさを調節する
  10. 低い倍率に戻してから、プレパラートを外して片づける

## 学習上のポイント

- 「粗動ねじ」「微動ねじ」という用語を最初から覚えるより、画面では **「ピント調節ネジ（大）」「ピント調節ネジ（小）」** と表し、役割から理解できるようにしています。
- 倍率は「接眼レンズの倍率 × 対物レンズの倍率」で求めます。例：10倍 × 4倍 ＝ 40倍。使用する顕微鏡によって、レンズの倍率や構造が異なる場合があります。
- 顕微鏡の景色は、プレパラートを動かす向きと反対に動いて見えます。
- 観察では、対物レンズをプレパラートにぶつけないよう、横から見ながら近づけることを大切にしています。直射日光を反射鏡で直接のぞき込むことは避け、学校で指示された明るい場所と方法で使います。

## 技術・運用

- 静的なHTML/CSS/JavaScriptで動作します。バックエンド、データベース、外部APIは使用しません。
- 3D表示には `vendor/three.min.js` を使用します。
- ナビキャラ画像は `TT-sensei/navi-character-` リポジトリの公開WebP画像を参照します。画像が読み込めない場合も、顕微鏡の操作や学習を続けられるようにしています。
- 主なファイルは `index.html` と `app.js` です。
